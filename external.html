Cloud Computing

Cloud computing is the on-demand delivery of computing services over the internet—including data storage, servers, databases, networking, software, and intelligence.
Instead of buying, owning, and maintaining expensive physical data centers and local hard drives, companies and individuals rent access to storage and computing power from cloud service providers (like Amazon Web Services, Microsoft Azure, or Google Cloud).

Why Cloud Computing is Widely Used

  • Cost Efficiency: Eliminates the capital expense of buying hardware and building on-site data centers. You only pay for the exact resources you consume (pay-as-you-go model).
  • Scalability: Resources can be scaled up or down instantly to meet heavy traffic spikes or reduced workloads without changing physical infrastructure.
  • Global Reach: Cloud services can deploy applications and data centers worldwide in minutes, providing low-latency access to users anywhere on the globe.
  • Reliability & Disaster Recovery: Data is typically backed up across multiple redundant sites, making data recovery easier and business continuity more secure in case of physical disasters.

The Three Main Service Models (SPI Model)

Service Model What It Provides Example Use Case / Providers
IaaS
(Infrastructure as a Service)		 The foundational building blocks. You rent raw virtual servers, storage space, and networking hardware. AWS EC2, Google Compute Engine. You manage the operating system and apps.
PaaS
(Platform as a Service)		 A managed environment designed for developers to build, test, and deploy software without worrying about underlying servers. Heroku, AWS Elastic Beanstalk.
SaaS
(Software as a Service)		 Fully developed, ready-to-use software applications delivered directly over the internet via a web browser. Google Workspace, Microsoft 365, Salesforce.
